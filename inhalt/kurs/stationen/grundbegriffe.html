Das Gedächtnis der KI

Eine KI sieht beim Antworten nur, was in ihr Kontextfenster passt. In einem langen Chat können die ersten Nachrichten herausfallen, mit ihnen wichtige Vorgaben. Mit JavaScript siehst du hier einen Chat, in dem genau das passiert.

Die Begriffe

Modell
Das trainierte Sprachmodell hinter einer App. Eine App kann mehrere Modelle anbieten, schnellere und gründlichere.
Prompt
Alles, was du der KI gibst: Auftrag, Fragen, Material.
Token
Die Stücke, in die das Modell Text zerlegt: ganze Wörter, Wortteile, Zeichen. Im Englischen ist ein Token im Schnitt etwa ein Dreiviertelwort, andere Sprachen brauchen meist mehr Token.
Kontext
Alles, was das Modell beim Antworten gleichzeitig vor sich hat: Chatverlauf, Dateien, Anweisungen. Das Kontextfenster ist groß, aber begrenzt. In langen Chats können frühe Teile herausfallen oder werden zusammengefasst, Details gehen dabei verloren.
Halluzination
Eine Angabe, die überzeugend klingt, aber falsch ist.
Agent
Eine KI, die nicht nur antwortet, sondern selbst Schritte ausführt, etwa suchen oder Dateien bearbeiten, bis eine Aufgabe erledigt ist.

Wichtige Vorgaben gehören deshalb an eine feste Stelle, zum Beispiel in die Anweisungen eines Projekts. Alle Begriffe ausführlich im Glossar.

Zum Mitnehmen

Wenn ein Chat lang wird: den Stand zusammenfassen lassen und mit der Zusammenfassung in einem neuen Chat weitermachen.

Fasse unser bisheriges Gespräch so zusammen, dass ich es in einem neuen Chat fortsetzen kann:
1. Ziel und Rahmen (Klasse, Fach, Termin)
2. alle Vorgaben und Einschränkungen, die ich genannt habe
3. was schon fertig ist
4. was noch offen ist
Schreib es als Text, den ich direkt in einen neuen Chat einfügen kann.
