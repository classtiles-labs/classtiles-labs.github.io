Deine Statusline

Ein Baukasten für die Zeile ganz unten in Claude Code: Modell, Ordner, belegter Kontext, Kosten, Wochenlimit, Denkstufe. Mit JavaScript wählst du hier die Bausteine, siehst die Zeile und kopierst das fertige Skript.

Was die Statusline ist

Die Statusline ist die Zeile ganz unten in Claude Code. Dort steht, was du ohne Nachfragen sehen willst: welches Modell arbeitet, in welchem Ordner und wie viel vom Kontext schon belegt ist. Ist der Kontext fast voll, lohnt sich eine neue Sitzung.

Am schnellsten richtest du sie mit dem Befehl /statusline ein. Du schreibst dazu, was du sehen willst, und Claude Code baut das Skript und trägt es selbst ein. Von Hand geht es mit den drei Schritten aus dem Baukasten: Claude Code gibt dem Skript die Daten der Sitzung, das Skript gibt eine Zeile zurück (Stand: November 2026).

Die Kosten sind eine Schätzung von Claude Code. Das Wochenlimit erscheint nur in Abos mit Nutzungslimit (Pro, Max, Ultra). Unter Windows läuft das Skript über Git Bash. Codex kennt ebenfalls /statusline, dort wählst du aus festen Bausteinen.

Zum Mitnehmen

In Claude Code eintippen. Die Bausteine kannst du frei austauschen.

/statusline Zeig mir das Modell, den Ordnernamen und wie viel Prozent des Kontexts belegt sind. Trenn die Teile mit einem senkrechten Strich.
