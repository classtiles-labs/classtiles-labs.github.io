Vom Satz zum Werkzeug

Ein Zeitraffer: Aus einem Satz wird in gut einer Minute ein Notenschlüssel-Rechner als einzelne HTML-Datei, mit Plan, Tests und einer Rückfrage. Dazu Claude Code und Codex im Vergleich. Mit JavaScript kannst du den Ablauf hier abspielen.

Was Coding-Agenten können

Claude Code von Anthropic und Codex von OpenAI sind Agenten, die in einem Ordner auf deinem Rechner arbeiten. Du beschreibst in normalen Sätzen, was entstehen soll. Der Agent plant, legt Dateien an, ändert sie, führt Befehle aus und prüft sein Ergebnis. Vor wichtigen Schritten fragt er nach, je nach Einstellung.

Für Lehrkräfte heißt das: Werkzeuge, die es so nicht zu kaufen gibt. Ein Notenrechner nach deinen Regeln, ein Quiz für das Whiteboard, eine Vorlage, die deine Arbeitsblätter einheitlich setzt. Programmieren musst du dafür nicht können, prüfen musst du das Ergebnis trotzdem.

Ein guter Einstieg: ein leerer Ordner, eine klare Beschreibung in drei Sätzen und die Bitte, zuerst einen Plan zu zeigen. Ordner mit Schülerdaten öffnest du einem Agenten nicht.

Zum Mitnehmen

Der erste Auftrag für Claude Code oder Codex, in einem neuen, leeren Ordner.

Ich möchte [Werkzeug] für meinen Unterricht in Klasse [Klasse].
Es soll [was es tut], bedient wird es von [wem], und es läuft auf [Gerät].
Es soll eine einzelne HTML-Datei sein, offline laufen und nichts speichern.
Zeig mir zuerst deinen Plan in Stichpunkten und warte auf mein OK.
Arbeite nur in diesem Ordner.
