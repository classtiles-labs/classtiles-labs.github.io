Ein Vorhaben in fünf Phasen

Ein nachgestelltes Beispiel: ein Vokabel-Quiz für Englisch in Klasse 6, gebaut mit Superpowers in fünf Phasen: Fragen, Entwurf, Plan, Bauen mit Tests, Prüfung. Mit JavaScript gehst du hier Phase für Phase durch und siehst, was ohne die Phase passiert.

Was Superpowers ist

Superpowers ist eine Sammlung von Skills für Coding-Agenten, geschrieben von Jesse Vincent und frei unter MIT-Lizenz. Die Skills geben dem Agenten eine Arbeitsweise: erst fragen, dann einen Entwurf schreiben, einen Plan machen, mit Tests bauen und am Ende prüfen lassen. Sie springen von selbst an, sobald du etwas bauen willst.

In Claude Code installierst du Superpowers mit /plugin install superpowers@claude-plugins-official, in Codex über /plugins und die Suche nach „superpowers“ (Stand: November 2026).

Es lohnt sich für Vorhaben, die größer sind als eine Datei: ein Werkzeug für die Fachschaft, eine kleine Website, ein Lernspiel mit mehreren Stufen. Kleine Änderungen stimmt der Agent weiter kurz im Chat mit dir ab. Der Preis: Am Anfang fragt er viel. Genau das spart später die Fehlersuche.

Zum Mitnehmen

Der erste Satz für ein größeres Vorhaben, mit oder ohne Superpowers.

Ich möchte [Werkzeug] für [Fach, Klasse] bauen.
Es soll [was es können soll], benutzt wird es von [wem].
Frag mich zuerst, bis du verstehst, wofür ich es brauche.
Zeig mir dann einen kurzen Entwurf. Den Plan erst nach meinem OK.
